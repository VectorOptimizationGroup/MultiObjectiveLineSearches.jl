# Installation

Requires Julia 1.11 or later. The package is not registered:

```julia
import Pkg
Pkg.add(url="https://github.com/VectorOptimizationGroup/MultiObjectiveLineSearches.jl")
```

For a local checkout:

```julia
Pkg.develop(path="/absolute/path/to/MultiObjectiveLineSearches.jl")
```

Continue with [Quick Start](@ref).
